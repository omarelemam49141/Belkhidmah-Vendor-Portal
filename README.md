# Belkhidmah MITM mock

Admin + provider screens for packages between provider websites (CRM) and بالخدمة.

```bash
npm install
npm run dev
```

Open http://localhost:3000

Razor login trial (daisyUI + Tailwind + Alpine + GSAP + htmx):

```bash
cd razor-trial
dotnet run
```

Open http://localhost:5015 — UI spec in `docs/design.md`.
